📖 简介

fd 与本篇为两部不同而独立的作品，并不是本篇的补丁内容，本篇的 Jast dlc 补丁仅针对 Steam 阉割的 H 剧情与去 cg 的码。

DL 的『电子版／数字版／下载版』版本为正版日文版普及版——语音语言均为日文。cg 有码，只有 Jast 发行的作品才被允许无码，日本规定必须有码才可以出版发行，因此日版原版与以日版为基础的民间汉化版的 cg 均有码；所以也希望大家能够多多支持 JASTUSA & Steam 正版，让 fd 可以有望提上日程。

可以使用 DL 官方翻译功能或直接使用广为流传的机翻软件——团子／Luna／VNR 等等。入正者也可申请本吧吧务组为入正者更方便地学习交流欣赏而整理提供的民汉辅助大全资料包（DMMd 吧本部保有翼梦与心游的原始转载授权），详见：【吧务】po 入正证明 x 申请专用帖

🎮 游戏内容

fd 篇游戏本体的主要内容为讲述【本篇 - HE 好结局】的后续、补充【本篇 - BE 坏结局】的故事，内容基本都是肉（fd 本来就是『Fan Disc』的简称，即”回馈粉丝”这种意味的作品）。

另外还有补充苍叶本人（童年）的故事、水纪纯友情向的后续故事、蚊香眼卡牌记忆消消乐小游戏、苍叶生日互动内容、像素动画（2012 愚人节限定特典『DRAMAtical Mother』）、『Dive into DMMd』先导情报信息等等。

📎 另外补充〖水纪线〗相关说明：真正意义上的〖水纪线（即可以攻略水纪）〗为 DMMd 本篇移植 PS／NS 的改编版『re：code』，相关说明见新编 code 专帖：【教学·说明·解疑】PS／NS 版 DMMd re：code 汇总帖

✅ 本篇（+ code 版本篇）→ ✅ fd → ✅ Dive into DMMd → ✅ DRAMA CD（角色后日谈 5 章）→ ✅ 官方夏日小说（summer side stories）

💻 系统

★ fd 普及版对应最适配的 Windows 系统为 Win10。Win11 认证问题请看：求助帖，大人们帮帮。若遇其他问题请开启兼容 Win10 模式尝试，或咨询 DL 官方客服等待回函教学。

★ 苹果 MacOS 系统的电脑可移步上一层楼工具汇总查看下载苹果系统相关工具，附苹果通用汇总：【教程】Steam 版正版 DMMd 本篇·苹果电脑端追加说明

★ LINUX 系统的电脑同样移步上一层楼工具汇总查看下载 LINUX 相关工具。

★ 手机／平板移动设备的运行不再赘述，不作解疑和相关分享，可参考手机啃机翻玩咎狗の血 True Blood 教程（认证问题需自行查阅资料，不作教学分享）；安卓运行民汉辅助包可参考：【教程】关于如何在手机上运行 dmmd 续篇与本篇解决立绘问题。苹果 iPhone／iPad 可在 B 站参考”UTM”模拟 Win10 系统的教学视频，也可在 B 站搜索”苹果 & gal”按照男性向作品的教学尝试（男性向的此类教学比较多 (◞‸◟)）。

💳 DLsite 入正途径说明

圈内虽有”Вiть形式容易被封号”的说法，但那绝大多数都是通过不正规途径充值点数／购买作品所造成的后果，所以若是找 Вiть 点数代买的话请务必擦亮眼睛明辨是非。

当然，若实在担心，各位也可自行寻找别的入正教学、使用其他入正方式——例如支付宝兑换点数、日本信用卡等等。

🚀 补充：加速器「选区」问题

NC 社游戏本体都没有强制要求限定日本区域的连接节点，公式书一类会需要限定日本 IP。

但若普通区域登入不了，一律最推荐选择日本的 IP 节点、并多多更换节点尝试。
