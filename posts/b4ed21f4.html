关于压缩包及游戏安装那些事

发表于2026-10-09|更新于2026-10-09|教程
|总字数:1.3k|阅读时长:4分钟|浏览量:

一、关于解压（WIN11可以直接解压但还是建议下一个）

解压软件（个人推荐）

1. 7-Zip（电脑）

官网：https://www.7-zip.org/

选择64位版本，点击Download即可进行下载

2. WinRAR（电脑）

官网：https://www.winrar.com.cn/

首页点击”立即下载”即可（如果弹出试用多少天然后要求你付费，无需理会，超过了也什么都不会发生）

下载完成后打开exe文件进行安装

第一次打开压缩包可能要选择打开方式为所安装的解压软件才行，之后就不用再选啦

3. MT管理器（手机）

手机上比较推荐这款软件，压缩包点一下就直接打开了（虽然手机自带的文件管理有同样的效果，但这个操作感觉更便捷）

MT的简单操作：

①打开压缩包后长按其中的文件会弹出操作页面（如图1），点击”解压”即会将文件解压到另一侧的文件夹中

②按住一个文件并往左/右任意方向滑动即可选中，此时再以同样的方式滑动同目录下的上/下的文件，即可选择这两个文件中间范围内的全部文件（如图2）。滑动选中一个文件后再单次点击即可不连续地选择文件

（二）特殊的压缩包（分卷压缩）

有的资源下载下来却是这样分了好几个压缩包，后缀前还有”part1、2、3””part01、02、03”。

这种分卷只要把所有压缩包下载下来，放在同一个文件夹下随便点开一个就可以啦，里面的文件就是这几个分卷下的全部内容了。

二、ISO资源的安装

1. WIN8及以后的系统支持直接打开ISO啦

2. 7-ZIP和WINRAR也可以直接打开ISO

3. 下载DAEMON Tools

官网：https://www.daemon-tools.cc/chn/home

选择下载DAEMON Tools Lite就可以了，打开exe文件进行安装

安装后选择”免费许可”

软件运行时打开ISO文件，选择用此软件查看就可以安装游戏啦

打开ISO文件后不管是什么语言还是乱码，点击看着像下一步的那个按钮就对啦→

下一步要设定安装路径（除C盘外找个喜欢的地方）

接着下一步，就会安装在电脑上了，根据你安装的路径找到文件夹，点击其中exe文件即可开始游玩

⚠️ 注：目前发现新版本的DAEMON TOOLS LITE携带风险程序，慎用！

上图为Virus Total对其检测的结果

4. 下载ImgDrive（占用超小不臃肿）

官网：https://www.yubsoft.com/imgdrive/

选择第一个绿色按钮”Download Installer”，下载好后进行安装。

ISO文件可以拖进软件打开，也可以右键选择ImgDrive打开。

⚠️ 注：uninst为卸载程序，不要点！！！（想卸载的时候可以点这个卸载）

有的比较特殊，ISO分为两个部分，遇到时应该会有教程如何安装

三、其他

（一）改后缀

有的文件明明该是压缩包的，但是后缀是乱七八糟的甚至根本没后缀，解压软件也打不开

选择文件，然后”重命名”

把”.”这个点点后的字改成”rar”、”zip”等，之后就可以正常打开了

注：有的电脑不显示后缀，请根据系统版本搜索如何显示文件后缀

（二）文件下载后的所在路径

绝大多数软件都可以在设置里查看下载路径，电脑上的下载后可以右键打开文件所在的文件夹。
部分软件下载路径随时都可能会变。

1. 电脑

打开”此电脑”（找不到就根据电脑系统版本搜索如何把”此电脑”放桌面上）

① 一般浏览器下载的默认在左侧边”下载”栏里，或者找 C: → Users/用户 → 本机用户名 → Downloads/下载，实在找不到就搜所用浏览器的下载路径在哪

② 百度网盘 在你所安装度盘的地方 → BaiduNetdiskDownload，找不到可以在文件资源管理器使用右上角搜索

③ 迅雷 在你所安装迅雷的位置 → 迅雷下载

④ 夸克网盘 默认也在Downloads里，和浏览器一样

⑤ 微信 在 C: → Users/用户 → 本机用户名 → Documents → WeChat Files → wxid_（后面一长串）→ FileStorage → File →（打开对应日期的文件夹），因为找起来有些麻烦，最好在微信聊天里右键接收到的文件后选择”在文件夹中显示”

⑥ QQ 默认在Downloads里，和浏览器一样

2. 手机（变动频繁，不一定在何时都准确）

推荐使用MT管理器来进行文件的查找与操作

① 系统自带浏览器和谷歌浏览器一般都在根目录下的Download里（小米手机默认下载到Download→DLManager，无法更改）

② 百度网盘 有可能在根目录下的BaiduNetdisk也有可能在Download→BaiduNetdisk

③ 迅雷 在 Android → data → com.xunlei.downloadprovider → files → ThunderDownload

④ 夸克浏览器 在Download→QuarkDownloads

⑤ 微信 在Download→WeiXin

⑥ QQ 在 Android → data → com.tencent.mobileqq → Tencent → QQfile_recv 或 Download→QQ
