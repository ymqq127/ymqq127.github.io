发表于2026-11-09|更新于2026-11-14|游戏教程

本文整理自贴吧帖子 【资源·工具】DMMd等文字冒险游戏·通用实用工具汇总。汇总 DMMd（DRAMAtical Murder）等 N+C 社作品、以及其他同类文字冒险游戏都能通用的各类实用工具，附下载指路与说明。

吧友们如果有更好的资源教程，欢迎到原帖补充或单开帖分享；链接失效会不定期补档，失效了也可自行到各类论坛 / GitHub 寻找。有能力请务必支持正版或补票正版。

🗜️ 解压软件

所有游戏安装包、各类资源，都需【解压】后再安装/运行/使用——尤其 Win11 现在基本能直接点进压缩包预览，千万不要不解压直接预览使用，否则程序类资源很大概率会出各类 bug/报错。

✅ 安装前请关闭网络、杀毒软件和防火墙，否则易安装失败。
🔺 解压类软件装一个就够了，挑顺手的即可，不用下很多个。
❓ 出现报错请按报错编码自行百度。

WinRAR

  • 作用：Windows 系统电脑解压软件
  • 下载：【资源·工具】解压软件 WinRAR
  • 备份：WinRAR 安装包夸克下载

7-Zip

  • 作用：Windows 系统电脑解压软件
  • 下载：【资源·工具】解压软件 7-Zip

Bandizip

  • 作用：Windows 系统电脑解压软件；压缩包格式兼容性较好，报「损坏」时可考虑用它强制解压
  • 下载：含教程 ｜ BandiZip + WinRAR ｜ BandiZip 夸克下载
  • 说明：补档清算文件首选「zpaq」格式压缩包，申请入正辅助获得的请用 Bandizip 解压

Mac-Unarchiver

  • 作用：苹果 macOS 系统电脑解压软件
  • 下载：【资源·工具】解压软件 苹果电脑 Mac-Unarchiver

🪟 Mac / Linux 运行 Windows 环境

  • 下载：【游戏】MacOS Big Sur 版模拟器（含教程，下载见 4 楼、5 楼楼中楼）
  • 说明：MacOS 实现 Windows 环境汇总帖（Steam 版正版 DMMd 本篇）

CrossOver

  • 作用：macOS、Linux 电脑模拟 Windows 环境，运行同类文字冒险游戏
  • 下载：【资源·工具】MacOS、Linux 系统 CrossOver
  • 说明：同上 MacOS 实现 Windows 环境汇总帖

🌐 转区

Locale Emulator

  • 作用：Windows 模拟特定区域系统环境，解决日文、英文、繁体中文等原版游戏文字乱码 / 无法正常显示的问题

VMware 虚拟机 + 模拟 Windows XP

  • 作用：解决古早系统 exe 程序（游戏、翻译电子书等）在新系统新电脑上运行不了或运行报 bug
